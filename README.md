Rupia: Crypto to PKR Bridge
Rupia is a fast, secure bridge that sends crypto (USDT, USDC, or ETH) from the zkSync network directly to Pakistani bank accounts via Raast/any bank.

How It Works
Lock Assets: You send crypto to a smart contract. You keep full control of your wallet.

Verify: The system waits for  block confirmations (~5 seconds) to ensure the transaction is safe and final.

Release Payout: Once confirmed, our system triggers the Raast API to send PKR to your bank account instantly.
